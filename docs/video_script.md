# Production Planner Video Tutorial Script

**Setup:**
1. Open two browser tabs:
   - **Tab 1:** `http://localhost:8000/notepad.html` (for text explanations)
   - **Tab 2:** `http://localhost:8000/index.html` (the application)

**Recording Steps:**

1.  **Intro (Tab 1 - Notepad):**
    *   Type: `Panduan Production Planner.`
    *   Type: `1. Pilih Departemen Croissant.`

2.  **Action (Tab 2 - App):**
    *   Click "Select Department" -> Choose **Department Croissant**.
    *   Click the **Planner** button.

3.  **Instruction (Tab 1 - Notepad):**
    *   Type: `2. Masukkan Produk dan Jumlah.`

4.  **Action (Tab 2 - App):**
    *   Row 1: Select **Plain Croissant**.
    *   Qty: Type **48**.
    *   *Pause briefly to show calculations.*

5.  **Instruction (Tab 1 - Notepad):**
    *   Type: `3. Tentukan Lebar Sheet & Auto Hitung Panjang.`

6.  **Action (Tab 2 - App):**
    *   Sheet Width: Change to **60**.
    *   Sheet Length: Click **Auto** button.
    *   *Pause to show result.*

7.  **Instruction (Tab 1 - Notepad):**
    *   Type: `4. Gunakan Merge Layout untuk gabung produk.`

8.  **Action (Tab 2 - App):**
    *   Row 2: Select **Pain Au Chocolat**.
    *   Qty: Type **24**.
    *   Click **Merge Layout** (brown button).
    *   *Show modal for 3 seconds.*
    *   Close modal.

9.  **Outro (Tab 1 - Notepad):**
    *   Type: `Selesai. Terima Kasih.`
